# Dynamic Island для MacBook

Приложение превращает вырез экрана в интерактивный «остров»: наведи на него курсор, и он раскроется.

- **Музыка**: обложка, название, перемотка и кнопки управления. Смена трека анимируется, а подсветка берёт цвет обложки. Работает с Apple Music, Spotify, Яндекс Музыкой, YouTube Music (в браузере или в десктоп‑клиенте) и с любым другим плеером, который передаёт данные в системный виджет «Сейчас играет». Во время воспроизведения в свёрнутом острове видны обложка и эквалайзер, а при смене трека ненадолго появляется его название.
- **Файлы**: сюда можно перетащить файлы из Finder, и остров раскроется сам. Потом файлы можно вытащить обратно куда угодно. В контекстном меню есть «Открыть», «Показать в Finder», AirDrop и «Скопировать путь».
- **Заметки**: быстрые заметки, которые сохраняются автоматически.
- **Управление**: ползунки громкости и яркости. Когда громкость или яркость меняются клавишами, остров показывает индикатор.

## Сборка

Достаточно Command Line Tools, Xcode не нужен.

```bash
./build.sh
open build/DynamicIsland.app
```

Меню приложения находится в строке меню (иконка капсулы). Там можно включить запуск при входе, очистить файлы и выйти.

## Как это устроено

- `MediaAdapter/`: с macOS 15.4 сторонние приложения не могут читать `MediaRemote` напрямую. Поэтому небольшая библиотека загружается в системный `/usr/bin/perl` и передаёт состояние плеера строками JSON. Если этот путь не работает, Apple Music и Spotify опрашиваются через AppleScript.
- Яркость меняется через `DisplayServices`, громкость через CoreAudio.
- Список файлов и заметки лежат в `~/Library/Application Support/DynamicIsland/`.
- `DynamicIsland --snapshots <папка>` рендерит все состояния острова в PNG.
